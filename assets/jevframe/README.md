# Official jevframe logo

Two isometric corners frame `df.jev()`. The corners are adapted from the
[TypeSafe AI mark](https://typesafe.ai/), separated horizontally while retaining
their staggered heights. The SVG embeds the original filled mark path from
`../typesafe-ai/logo-dark.svg` unchanged and reuses it twice with clipping paths
and horizontal translations. The corners are not reconstructed with strokes.

- `logo.svg`: transparent vector master, 693 × 192. Menlo Bold lettering is
  converted to paths, so no font installation is required.
- `logo.png`: transparent PNG, 1386 × 384.
- `preview.png`: the same logo on a pale pink background, 1386 × 384.

Ink: `#1e1e1e`. Preview background: `#f8ebf7`.
